# Configuração operacional do job geo-file

- `downloads/downloadThemesConfig.json` — cópia sincronizada do
  `dsp-backend/config/downloads/` (gerada pelo `./config.sh` do dsp-core).
- `docker/entrypoint.sh` — entrypoint da imagem Docker.

Configuração Spring estrutural: `src/main/resources/application.properties`.
